# 🍚 찐 맛집 찾기

리뷰 별점 부풀리기(대가성 리뷰 등)를 걸러낸 "보정 별점"과 판정을 지도 위에 보여주는
개인 프로젝트입니다.

**지도 보기:** https://tjdgusk251.github.io/real_review/

- 초록 핀 = 찐후보 (검증점수·별점·리뷰량이 모두 뒷받침되는 곳)
- 연두 핀 = 좋음 / 빨강 = 과대평가 의심 / 파랑 = 보통 / 회색 = 정보 부족
- 핀을 누르면 판정 근거, 강점/약점 키워드, 영수증 인증·재방문자 비율이 표시됩니다

수집된 지역만 조회할 수 있습니다. 데이터는 공개 플랫폼의 집계 수치를 바탕으로
자체 계산한 지표이며, 리뷰 원문은 포함하지 않습니다.
